# SelfUp — Tasking System Documentation (RPG Edition v2.0)

SelfUp is not a productivity app; it is a **life RPG**. Every real-world action is translated into in-world System events. This document provides a detailed technical and functional breakdown of the tasking architecture.

---

## 1. Vital Resources & Economy

The system is governed by three primary resources that create the urgency and reward loop.

### 1.1 XP (Experience Points)
The measure of growth and the fuel for Ascension.
- **Earn Rate:**
  - **Low Priority Task:** +5 XP
  - **Critical Task:** +35 XP
  - **Daily Habit:** +5 XP (Multiplied by STR if physical)
  - **Log Workout:** +25 XP (+2% per STR point)
  - **30-min Skill Session:** +15 XP (+2% per INT point)
  - **D-Rank Dungeon Clear:** +200 XP
  - **S-Rank Raid Clear:** +1200 XP
- **Formula:** `xpToNextLevel = Math.floor(100 * Math.pow(level, 1.5))`

### 1.2 HP (Health Points)
The integrity of your Vessel. It represents consistency.
- **Base HP:** 100 (Scales with VIT: +15 Max HP per VIT point).
- **Damage Table:**
  - **Missed Habit:** -5 HP (Capped at -20 HP/day).
  - **Broken 7-day Streak:** -15 HP.
  - **Inactivity >48h:** -30 HP.
- **HP reaching 0:** Triggers **Level Regression** (lose 1 level) and a mandatory Recovery Quest.

### 1.3 AiCoins
The only in-app currency, used to access System intelligence.
- **Earned via:** Daily logins, quest completions, dungeon clears, or real-money purchase.
- **Usage Cost:**
  - **AI Chat:** 1 Coin
  - **Auto-Scheduling:** 5 Coins
  - **Skill Roadmap:** 15 Coins
  - **Streak Freeze:** 100 Coins

## 2. The Quest System

Quests are the primary vehicle for action. Every quest includes a **live ticking countdown timer** to drive urgency.

### 2.1 Quest Hierarchy
| Type | Duration | Reset Cycle | Difficulty | Description |
|------|----------|-------------|------------|-------------|
| **Daily** | 24h | Midnight | Easy | Basic habits and tasks. |
| **Weekly** | 7 Days | Monday | Medium | Cumulative goals (e.g., "5 Workouts"). |
| **Dungeon** | 24–72h | Daily/Weekly | Hard | Event-based high-reward gates. |
| **Story** | Multi-week | Never | Escalating | Narrative-driven progression milestones. |
| **AI Quest** | Custom | Never | Personalised | Generated by Gemma based on user's weak points. |

### 2.2 Dungeon Gates (Urgency Centerpiece)
Dungeons are shared or solo events with tiered rewards.
- **D-Rank (Solo):** 24h duration. Basic objectives like "Complete all habits".
- **A-Rank (Co-op):** Shared with guild members. Requires 60+ HP to enter.
- **S-Rank Raid Boss:** Guild-wide challenge against a shared HP pool (e.g., 5000 HP). Every member's action deals "damage" to the boss.

## 3. Attribute System — "Leveled by Doing"

Attributes reflect the user's real-life focus. They level up automatically based on qualifying actions.

### 3.1 STR (Strength)
- **Domain:** Physical development.
- **Leveled by:** Workouts, physical habits, fitness dungeons.
- **Bonus:** +5% XP gain from fitness actions per STR point.
- **Unlock:** STR 10 unlocks S-Rank workout dungeons.

### 3.2 INT (Intelligence)
- **Domain:** Mental development & Learning.
- **Leveled by:** Skill sessions, reading habits, milestones.
- **Bonus:** +10 max AiCoin daily pool per INT point.
- **Unlock:** INT 15 unlocks "Cognitive Probe" AI skill.

### 3.3 AGI (Agility)
- **Domain:** Discipline, speed, consistency.
- **Leveled by:** Timely task completion, streaks, Pomodoro sessions.
- **Bonus:** +1 AiCoin passive regen per day per AGI point.
- **Unlock:** AGI 10 allows Streak Freeze to auto-activate.

### 3.4 VIT (Vitality)
- **Domain:** Physical health and recovery.
- **Leveled by:** Sleep logging, water intake, recovery tasks.
- **Bonus:** Reduces HP damage by 10% for every 3 VIT points.
- **Unlock:** VIT 10 gives once-per-week immunity to inactivity penalty.

### 3.5 CHA (Charisma)
- **Domain:** Social influence and style.
- **Leveled by:** Friend challenges, guild raids, outfit logs.
- **Bonus:** +5% bonus XP contributed to Guild XP pool per CHA point.
- **Unlock:** CHA 5 allows guild creation; CHA 20 allows Guild Master status.

## 4. AI & System Mechanics

### 4.1 The System Window
The "System Window" is a high-dopamine UI event triggered by Level Ups, Rank Ups, or rare Loot Drops. It allows for manual stat allocation (+1 point per level).

### 4.2 AI Scheduler (Auto-Sync)
Gemma analyzes the user's "Critical Objectives" and current "Vessel State" (HP/Energy) to generate an optimized daily plan.
- **Action Parsing:** AI outputs `<action type="schedule">` JSON which is processed by the backend.
- **Cognitive Probe:** At high INT, the AI can predict when the user is likely to fail a habit and sends a proactive "Pre-emptive Warning".

### 4.3 Level Regression & Comeback
If HP hits 0, the player undergoes **System Downgrade**.
- **Penalty:** Lose 1 Level.
- **Comeback Path:** Immediate assignment of a "Restoration Protocol".
- **Reward:** Completing the comeback earns the rare **"System Override"** badge.

## 6. Module-Specific Protocols

### 6.1 Fitness Protocol (Warrior Class)
- **Workout Logs:** Detailed exercise-by-exercise tracking (`sets_done` JSONB).
- **Nutrition Logs:** Tracking meal types, calories, and macros (protein, carbs, fat).
- **Water Protocol:** Daily ML targets that contribute to VIT leveling and HP recovery.
- **Body Metrics:** Photo-based progress logs (`body_metrics`) for visual confirmation of the "Ascension."

### 6.2 Skill Protocol (Scholar Class)
- **AI Roadmaps:** `skill_roadmaps` generated via Gemma to provide a structured learning path.
- **Milestones:** Step-by-step goals within a skill (e.g., "Complete JS Basics").
- **Practice Sessions:** Time-based tracking (`skill_sessions`) with mood and point recording.

### 6.3 Style Protocol (Charisma Layer)
- **Outfit Logs:** Daily rating of personal presentation.
- **Style Recommendations:** AI-generated advice based on body type and "Style Vibe" (casual, formal, etc.).
- **Moodboard:** Collecting visual fragments of the user's desired "Final Form."
