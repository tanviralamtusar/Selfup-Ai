# SelfUp — Skills System Details

The **Skills System** is a core module of the SelfUp ecosystem designed to track real-world skill acquisition through an RPG-style progression lens. It combines session-based time tracking with AI-generated roadmaps and milestone-based rewards.

---

## 1. Database Schema

The skills module is powered by four primary tables in Supabase:

### `skills`
Stores the high-level information for each skill.
```sql
CREATE TABLE skills (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES user_profiles(id) ON DELETE CASCADE,
  name            TEXT NOT NULL,
  description     TEXT,
  category        TEXT,    -- 'coding', 'music', 'language', 'other'
  icon            TEXT,
  color           TEXT,
  tracking_mode   TEXT DEFAULT 'milestone' CHECK (tracking_mode IN ('time','milestone','points')),
  total_hours     DECIMAL DEFAULT 0,
  total_points    INT DEFAULT 0,
  streak          INT DEFAULT 0,
  streak_last_date DATE,
  is_active       BOOLEAN DEFAULT true,
  created_at      TIMESTAMPTZ DEFAULT now()
);
```

### `skill_roadmaps`
A container for a set of milestones, usually generated by AI.
```sql
CREATE TABLE skill_roadmaps (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  skill_id        UUID NOT NULL REFERENCES skills(id) ON DELETE CASCADE,
  user_id         UUID NOT NULL REFERENCES user_profiles(id) ON DELETE CASCADE,
  title           TEXT NOT NULL,
  is_ai_generated BOOLEAN DEFAULT false,
  created_at      TIMESTAMPTZ DEFAULT now()
);
```

### `skill_milestones`
Individual steps or learning objectives within a roadmap.
```sql
CREATE TABLE skill_milestones (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  roadmap_id      UUID NOT NULL REFERENCES skill_roadmaps(id) ON DELETE CASCADE,
  title           TEXT NOT NULL,
  description     TEXT,
  resources       JSONB,    -- [{type:'youtube', url:'...', title:'...'}]
  order_index     INT,
  is_completed    BOOLEAN DEFAULT false,
  completed_at    TIMESTAMPTZ,
  estimated_hours INT,
  xp_reward       INT DEFAULT 10
);
```

### `skill_sessions`
Logs of individual practice or learning sessions.
```sql
CREATE TABLE skill_sessions (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  skill_id        UUID NOT NULL REFERENCES skills(id) ON DELETE CASCADE,
  user_id         UUID NOT NULL REFERENCES user_profiles(id) ON DELETE CASCADE,
  session_date    DATE NOT NULL DEFAULT CURRENT_DATE,
  duration_minutes INT,      -- Practice duration in minutes
  points          INT,       -- Optional points earned
  notes           TEXT,
  mood            INT CHECK (mood BETWEEN 1 AND 5),
  xp_earned       INT DEFAULT 0,
  created_at      TIMESTAMPTZ DEFAULT now()
);
```

## 2. System Mechanics

### Skill Creation & AI Roadmaps
When a user creates a new skill, they can choose to **Generate AI Roadmap**. 
- The system adds a task to the `ai_queue` with `action_type: 'roadmap'`.
- A background worker (using BullMQ) processes the job:
    1.  **AI Prompting**: It sends a prompt to the AI (Gemma/GPT) asking for 8-10 actionable milestones for the specific skill and category.
    2.  **JSON Structure**: The AI must respond with a JSON array of objects: `{ "title", "description", "estimated_hours" }`.
    3.  **Database Insertion**: The worker creates a `skill_roadmaps` record and bulk-inserts the generated milestones into `skill_milestones`.
- **UI Feedback**: The frontend listens for the status update in `ai_queue` and notifies the user once the roadmap is ready.

### Learning & Progression
Progression is tracked via **XP (Experience Points)** and **Attributes**.
1.  **Session Rewards**: By default, users earn **1 XP per minute** of practice logged in `skill_sessions`.
2.  **Milestone Rewards**: Completing a milestone in a roadmap awards a flat XP bonus (e.g., 10-50 XP).
3.  **Intelligence Bonus**: Skill actions are mapped to the **Intelligence (`int`)** attribute.
    - **XP Modifier**: In `TaskEconomyService`, the `skills` category applies an `attr_int` bonus.
    - `XP = Base_XP * (1 + 0.005 * attr_int)` — meaning every point in Intelligence provides a +0.5% XP boost to learning.

### Attribute Growth
Practicing skills directly feeds back into the user's RPG stats.
- **Intelligence (`int`)**: Managed by `AttributeService`.
- **Logic**: For every **1 hour** of total skill practice (accumulated across sessions), the system checks for an Intelligence point gain.
- **Thresholds**: Points are awarded based on `ATTRIBUTE_GAIN_THRESHOLDS`.

## 3. Key Code Structure

### Backend (API Routes)
- `GET /api/skills`: Lists all active skills with their milestone progress.
- `POST /api/skills`: Creates a new skill and optionally triggers AI roadmap generation.
- `POST /api/skills/[id]/sessions`: Logs a new practice session and awards XP.
- `GET /api/skills/[id]/roadmap`: Fetches the current roadmap and milestones.

### Services (Logic Layer)
- `AttributeService.ts`: Counts `skill_session` duration to calculate Intelligence gains.
- `GamificationService.ts`: Handles global XP addition and level-up events.
- `TaskEconomyService.ts`: Maps the `skills` category to the `attr_int` attribute for XP multipliers.
- `QuestService.ts`: Updates progress for quests that require "Complete X skill sessions".

### Frontend (Components)
- `SkillCard.tsx`: Displays skill progress, current level, and total hours.
- `RoadmapTimeline.tsx`: Visualizes the learning path and milestone completion status.
- `SkillsPage`: The main dashboard for managing and tracking all skills.

## 4. Integration with Other Systems

- **Tasks & Habits**: Skills can be linked to daily tasks or habits (e.g., "Practice Guitar for 30 mins").
- **Quests**: The "Scholar" or "Polymath" quest lines require logging skill sessions.
- **Dungeons**: Intelligence-based challenges in Dungeons may be easier for users with high `attr_int` (earned via skills).
- **YouTube API**: Integrated into the roadmap view to fetch tutorials for specific milestones.
- **AI Persona**: The AI coach uses skill data to provide personalized encouragement (e.g., "I see you've put 10 hours into Coding this week, impressive!").

---

## 5. Development Rules (Skill-Specific)
1.  **XP Accuracy**: Always use `GamificationService` or `TaskEconomyService` to award XP to ensure attribute bonuses are applied.
2.  **Roadmap Integrity**: When updating milestones, ensure `order_index` is preserved.
3.  **Session Idempotency**: Verify session dates to prevent double-logging for the same time period.

## 6. YouTube API Integration

The Skills module leverages the YouTube Data API v3 to provide users with immediate learning resources for their milestones.

### Backend Implementation
- **Route**: `POST /api/youtube/search`
- **Logic**:
    1.  **Contextual Search**: The system automatically appends " tutorial" to the user's milestone or skill query to ensure relevant educational content.
    2.  **API Fallback**: If the `YOUTUBE_API_KEY` is not configured in `.env`, the system serves stylized mock data to ensure the UI remains functional during development.
    3.  **Simplified Response**: The API maps the verbose YouTube response into a clean object containing `id`, `title`, `channelTitle`, `thumbnail`, and `link`.

### Frontend Usage
- **Component**: `RoadmapTimeline.tsx`
- **Trigger**: The user clicks the **"Find Resources"** button on a specific milestone.
- **Query Context**: The system sends a combined query of `${skillName} ${milestone.title}` to provide the most relevant tutorial context.
- **Display**: Results are rendered as a dropdown list of video cards within the milestone's expanded view, featuring:
    - Video Thumbnail
    - Channel Name
    - Video Title (with "tutorial" context appended on the backend)
    - External Link to YouTube
